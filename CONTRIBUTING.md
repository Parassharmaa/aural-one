# Contributing

Issues and pull requests are welcome for the loader, training recipe, evaluation protocol, and documentation. Include the exact GitHub commit, Hugging Face model revision, Python/PyTorch/Transformers versions, GPU, input duration, and a minimal reproduction when reporting a bug. Do not attach private recordings, credentials, or dataset material without permission to share it.

For evaluation contributions, state the independent sampling unit, split and speaker/source separation, sample count, metric, and whether examples were used for model selection. Report both improvements and regressions. For a proposed checkpoint change, compare against the frozen preview on the same rows and preserve typed-decision results.

The project code is Apache 2.0. Contributed audio, annotations, and pretrained weights may have separate terms; cite the source and confirm reuse rights before adding any such material. The repository does not host the training datasets.
